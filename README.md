# Caderno Livre

Site de estudos para o ENEM, sem cadastro e sem backend. O progresso, os favoritos e a última aula aberta ficam salvos no `localStorage` do navegador.

## Conteúdo

- Matemática
- Português e Literatura
- Artes
- Educação Física
- História
- Geografia
- Filosofia
- Sociologia
- Biologia
- Física
- Química

Os conteúdos foram organizados a partir dos cadernos do projeto e preservam a estrutura de explicação, **Como cai no ENEM**, **Pegadinhas**, fórmulas e exercícios quando presentes na fonte.

## Rodar localmente

Abra `index.html` no navegador ou use um servidor estático simples. Não há dependências nem etapa de build.

## GitHub Pages

Como o projeto é totalmente estático, pode ser publicado diretamente com GitHub Pages usando a branch `main` e a pasta raiz.
